# ファイル圧縮君

画像・PDF・動画・音声を、ブラウザの中でまとめて軽くするアプリです。

**HTML単体／外部通信なし／ログイン不要／ドラッグ＆ドロップ・タッチ操作対応。**
処理に必要なライブラリとPDF用のフォント・文字マップ・デコーダーを `index.html` に同梱しています。CDNは利用しません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 複数ファイルを選択、またはドラッグ＆ドロップします。
3. 圧縮方法・圧縮の強さを選び、処理を開始します。
4. 容量を確認し、別名で個別保存、またはZIPでまとめて保存します。

元ファイルは上書きしません。初期設定では、圧縮後に大きくなる場合は元ファイルを使います。
同名ファイルをZIPに入れる際は連番で区別します。ZIPを新規作成した後は、保存ボタンをもう一度押して保存します。
1ファイル300MB・合計600MB・100件まで。端末のメモリによっては、それ以下でも処理できない場合があります。

## 対応内容

| 種類 | 圧縮方法・調整 | 主な入力 | 出力・注意点 |
| --- | --- | --- | --- |
| 画像 | 画質・長辺サイズを調整 | JPEG、PNG、WebP、BMP、GIF、AVIFなど | JPEG／WebP／PNG。PNGはサイズ縮小のみ。JPEGでは透過部分は白色。アニメーションは最初の1コマ。付加情報は引き継ぎません。 |
| PDF：文字・リンク保持 | オブジェクト構造を再保存 | 暗号化されていないPDF | PDF。画像の画質は変えず、削減は控えめ。「圧縮の強さ」は影響しません。 |
| PDF：画像化 | 解像度・JPEG画質を調整 | 暗号化されていないPDF | PDF。文字選択・検索・リンク・フォーム・しおり・添付ファイルを引き継ぎません。 |
| 動画 | 解像度・フレームレート・ビットレートを調整 | MP4、WebM、MOVなど | ブラウザに応じてMP4／WebM。字幕・複数音声・HDRを保持しません。 |
| 音声 | ビットレートを調整 | MP3、M4A、AAC、WAV、OGG、FLACなど | ブラウザに応じてM4A／WebM音声／OGG。MP3での出力は非対応。曲名・ジャケットなどを引き継ぎません。 |
| 元ファイルをZIPに | ZIPの圧縮レベルを調整 | 形式を問わず対応 | 内容・形式・画質を変更せずZIPに格納します。ZIPは暗号化されません。 |

入力形式・コーデックはブラウザの対応に依存します。HEIC・TIFFなどは一部の環境で読み込めません。
PDFはパスワード付き・暗号化ファイルに対応しません。再保存したPDFでは電子署名の有効性が失われます。
すでに圧縮されたJPEG・MP4・MP3などは、ZIP化しても小さくならず、容量が増えることがあります。
「圧縮の強さ」は品質設定であり、指定の削減率を保証する機能ではありません。

## 動画・音声について

- 再生しながら変換するため、ファイルの再生時間と同程度の時間がかかります。
- 変換中は画面を開いたままにしてください。画面を閉じたり他のアプリへ切り替えたりすると中止します。
- 自動再生が制限されている場合は、画面に表示される開始ボタンを押してください。
- マイク・カメラは使いません。変換中の音声はスピーカーへ出しません。
- 端末によってMP4／WebMなどの出力形式が異なります。WebMの再生・シーク対応も再生ソフトに依存します。
- 対応しないファイルはエラーを表示し、他のファイルの処理を続けます。

## オフラインとプライバシー

Mac・Windowsでは、ダウンロードした `index.html` だけをブラウザで開けばオフラインで利用できます。インストールやビルドは不要です。
画像・PDF・動画・音声の内容やファイル名を外部に送信しません。解析・広告・外部フォント・CDN・サーバーAPIは使いません。
ネットワーク接続を禁止するContent Security Policyも設定しています。処理用のWorkerやPDFリソースはHTMLに同梱したデータから生成します。

GitHub Pagesなどの公開ページを最初に開く際は、HTMLを取得するための通信が発生し、配信元に通常のアクセス情報が伝わります。
OS・ブラウザの機能、ファイル選択元や保存先のクラウド同期などによる通信は、このアプリの処理とは別です。

iPad・iPhoneの「ファイル」アプリでHTMLをプレビューするだけでは、JavaScriptが動作しない場合があります。
Safariで公開ページを開くか、ローカルHTMLを実行できる環境を利用してください。**iPadでのHTML単体のオフライン実行は、利用環境に依存します。**
最新のChrome・Edge・Safariを想定していますが、すべての端末や形式での動作を保証するものではありません。

## GitHubにそのままアップする

このフォルダの中身を、新しいリポジトリのルート（最上位）にアップしてください。おすすめのリポジトリ名は `file-asshukukun` です。

```text
index.html                 完成版。これ1つで動作
README.md                  説明書
LICENSE                    共通の非商用ライセンス・免責事項
THIRD_PARTY_NOTICES.txt     同梱ライブラリのライセンス全文
robots.txt                 検索クローラー向け設定
.nojekyll                  GitHub Pages用
src/                       編集用ソース
build.mjs                  HTML単体にまとめるビルドスクリプト
package.json
package-lock.json
VALIDATION.md              実施した確認と未確認事項
```

GitHub Pagesで公開する場合は、Settings → Pages → Deploy from a branch → `main` → `/(root)` を選びます。
GitHub Pagesは公開サイトです。`noindex` と `robots.txt` は検索への掲載を抑制する設定であり、アクセス制限ではありません。
利用者はアプリ下部の「このアプリのHTMLを保存」からHTML単体を保存できます。

## ソースから作り直す場合だけ

Node.js 20.19以上（22系では22.13以上）で以下を実行します。依存パッケージの取得時には通信しますが、完成したアプリの実行時には通信しません。

```sh
npm ci
npm run build
```

`src/` を修正して再ビルドすると、`index.html` と `THIRD_PARTY_NOTICES.txt` が更新されます。
